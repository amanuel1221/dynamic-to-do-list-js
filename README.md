
# dynamic-to-do-list-js 

A simple dynamic to-do list web application built with HTML, CSS and vanilla JavaScript. You can add tasks, remove them, and manage your list directly in the browser — no backend needed.  

## Demo  
Live demo available at: https://dynamic-to-do-list-js-sigma.vercel.app/  

## Features  
- Add a new task  
- Delete a task  


## Tech Stack  
- HTML  
- CSS  
- JavaScript
